# FreeCore 官方交流群 群规

欢迎加入 **FreeCore（自由核心）** 官方交流群：`1085070135`！   
为了维护良好的交流环境，请**所有成员**遵守以下规定。

---

## 一、基本规范

1. **文明发言**，禁止人身攻击、辱骂、恶意嘲讽他人
2. 禁止发表**政治、宗教、地域歧视**等敏感言论
3. 禁止发布**色情、暴力、赌博**等违规内容
4. 禁止**刷屏**（连续无意义消息、大量表情包轰炸等）
5. 禁止**恶意引战**、挑拨群内矛盾

## 二、广告与外链

1. 禁止发布与 FreeCore 无关的**广告、推广信息**（包括但不限于其他服务器、商业推广、代练代肝等）
2. 禁止发布**未经允许的外部链接**，尤其是可能含有木马、钓鱼性质的链接
3. 如需分享 FreeCore 相关内容（视频、图片、建筑作品等），欢迎发布

## 三、账号与隐私安全

1. 禁止在群内**索要或交易账号密码**
2. 禁止打探、公开他人**真实姓名、住址、联系方式**等隐私信息
3. 谨防冒充管理员/客服私聊索要账号信息的诈骗行为，官方**不会**主动私聊索要密码

## 四、游戏相关

1. 游戏内的纠纷（如偷盗、破坏、诈骗交易等）请**优先在游戏内联系管理员**处理，群内可作为补充反馈渠道
2. 禁止在群内**恶意举报、诬陷**其他玩家
3. 服务器公告、维护通知、版本更新等信息将在群内发布，请留意置顶消息

## 五、违规处理

| 违规程度 | 处理方式 |
|---------|---------|
| 轻微违规（如刷屏、轻度不文明用语） | 口头警告 / 禁言 |
| 中度违规（如发布广告、外链） | 禁言 + 视情况关联游戏内处罚 |
| 严重违规（如辱骂他人、发布违规内容、诈骗） | 踢出群聊，视情节严重程度关联游戏内封禁 |

管理员保留对违规行为的最终解释权和处理裁量权。

## 六、联系方式

- 游戏内相关问题：联系在线管理员
- 群内违规举报：请 @管理员 或私聊反馈，并附上相关截图证据
