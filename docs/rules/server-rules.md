# FreeCore 服务器条款

本条款适用于所有进入 FreeCore 服务器的玩家。连接服务器即表示你已阅读并同意遵守以下内容。

## 1. 基本行为

- 尊重其他玩家，不进行辱骂、骚扰、歧视、恶意刷屏或煽动冲突。
- 不得冒充管理员、客服或其他玩家，不得诱导他人泄露账号、密码或验证码。
- 使用中文或服务器允许的语言交流，保持频道整洁，避免发布违法或不适宜内容。

## 2. 游戏公平

- 禁止使用外挂、作弊客户端、透视、脚本宏、自动点击器及任何破坏公平性的工具。
- 禁止利用漏洞刷取资源、复制物品、绕过限制或干扰服务器服务；发现漏洞请及时报告。
- 禁止恶意卡服、制造高频红石/实体负载、攻击服务器网络或试图绕过封禁。

## 3. 建筑与财产

- 未经允许不得破坏、占用或窃取他人建筑、箱子、村民和领地内的资源。
- 大型工程、公共设施和高负载装置应提前规划，必要时接受管理员的性能调整建议。
- 发现争议时请保留截图、坐标和时间，提交工单后等待管理员处理，不要自行报复。

## 4. 处罚与申诉

管理员会根据违规程度采取警告、禁言、回档、没收、临时封禁或永久封禁等措施。

处罚如有误判，可在申诉渠道说明经过并提供证据。申诉期间请勿重复刷屏或攻击处理人员。

## 5. 条款更新

FreeCore 会根据版本更新、社区发展和安全需要调整条款。重大变更会在公告中说明；继续游玩即视为**接受**更新后的条款。
