# Res领地圈地教程

> 本服圈地工具是 **箭矢（Arrow）**。

---

## 一、圈地的基本原理

圈地本质上就是：**用箭点两个"对角"，系统会自动把这 两点 之间的 长方体区域 框出来**，这块区域就是你的领地（Residence，简称 res）。
  
<img width="800" height="400" alt="res" src="https://github.com/user-attachments/assets/2bbe46bc-42e0-4455-8f89-def087c3c34f" />  

只要点出 P1、P2 两个点，系统就会自动把 P1、P2 所在的长方形区域用红色粒子标记出来，**不需要把四个角都点一遍**。

---

## 二、圈地步骤

### 第 1 步：创建选区
按照 [圈地的基本原理](#一圈地的基本原理) 进行选区

### 第 2 步：创建领地

建议先检查一下选区大小，别选太大超出限制：

```
/res select size
```

确认没问题后，给你的地皮起个名字并创建（这里我取名为“我的小屋”）：

```
/res create 我的小屋
```

聊天区域看到类似下面的提示，就说明 **圈地成功** 啦：

```
你创建了领地 我的小屋!
```
圈地价格：
```
0.70 H币 / 格
```

## 四、常用指令

### 传送到指定领地
```
/res tp <领地名称>
```

### 设置公共权限
打开权限设置菜单
```
/res set <领地名称>
```
设置单个权限
```
/res set <领地名称> [权限英文名称] [true/false/remove]
```

### 设置指定玩家权限
打开指定玩家权限设置菜单
```
/res pset <领地名称> [玩家名称]
```
设置指定玩家的单个权限
```
/res pset <领地名称> [玩家名称] [权限英文名称] [true/false/remove]
```

### 设置领地传送点
先走到你想要作为出生点的地方，然后：
```
/res tpset
```

### 查看自己拥有的领地
```
/res list
```

### 查看所处的领地边界
```
/res show
```

### 查看所处领地的所有者信息
```
/res info
```

## 五、圈地常见问题 FAQ

**Q：提示地皮大小/数量超出限制？**
A：每个人能圈的地皮大小和数量是有上限的，用 `/res limits` 查看你当前的额度。

**Q：选完两个角，中途想重新选怎么办？**
A：直接重新用箭点新的两个角就行，选区会被覆盖更新，不用专门"取消"。
